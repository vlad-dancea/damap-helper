# damap-helper

Watches a project folder and flags changes that contradict its data management plan in [DAMAP](https://github.com/tuwien-csd/damap-backend).

## Install

macOS and Linux:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/vlad-dancea/master-fooling-around/releases/latest/download/damap-helper-installer.sh | sh
```

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://github.com/vlad-dancea/master-fooling-around/releases/latest/download/damap-helper-installer.ps1 | iex"
```

Then, in your project folder:

```sh
damap-helper setup
damap-helper run
```

## Releasing

Bump `version` in `damap-helper/Cargo.toml`, commit, then push a matching tag:

```sh
git tag v0.1.0 && git push origin v0.1.0
```

GitHub Actions builds the binaries and installers and attaches them to a GitHub release. The workflow is generated by [dist](https://github.com/axodotdev/cargo-dist); after changing `dist-workspace.toml`, run `dist generate`.
